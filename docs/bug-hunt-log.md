| BH-15 | High (source revocation) | connected sources and Google OAuth | A revoked source was excluded from retrieval, but its mutation guard checked only ownership. | BH-16 | High (OAuth authorization) | connected Google sources | Google OAuth state was signed and expiring but stateless, so a captured callback state could be replayed during its validity window and was not durably bound to the operator who initiated consent. | **Resolved** - HAI stores only a SHA-256 state digest in PostgreSQL, bound to one source and verified owner. Revocation deletes pending attempts. Unit, HTTP, race, migration-contract, full-backend, and isolated PostgreSQL lifecycle tests pass. |

| BH-19 | High (lifecycle and execution control) | interactive workflow and agent-cycle runs | Authenticated HTTP requests used durable background-style workflow and source entry points.
