# Original Perl source qualification

This proposal prepares the publisher's stable Perl 5.44.0, including its original Archive::Tar 3.12, before a Debian runtime package replacement. The publisher archive matches the independently retained Debian original-source SHA-256. No development release, downloaded executable, source patch or original-case edit is selected. Detached PGP authentication has not been verified.

The hosted-only SDK uses pinned GCC 16.2 / Python 3.15.1 image digests. Its source worker refuses other interpreters, compilers, users and qualification environments. Actual compilation and vendor-case execution run as UID 10001 in a disposable, network-disabled, read-only-root container with no capabilities, no-new-privileges and bounded CPU, memory, process and temporary storage. No application workspace, private data, provider credentials or operator SDK is mounted.

Run the publisher's supported threaded/shared configuration, normal make, and full `TEST_JOBS=2 make test_harness` invocation without selecting a case subset or setting PERL_BUILD_PACKAGING. Retain complete stdout/stderr and every original source/case/helper hash. The 3,823 files under test directories are fixtures and helpers as well as test programs; that count is not a claim of 3,823 executed tests. Actual harness file/assertion counts and skip/TODO/expected-failure markers are recorded separately. A zero upstream harness exit establishes the supported SDK invocation only. Full original-case acceptance remains false if such markers appear; no unsupported platform, privileged, TTY or network behavior is declared accepted through a skip.

After successful source execution, install only to the private SDK tmpfs prefix and verify the actual Perl, compiler and Archive::Tar identities, threads, shared-library and 64-bit integer features. Retain the complete prefix archive, regular-file hashes and symlinks. This is neither a Debian runtime package nor an operator/application image installation. Actual Debian package controls, dependency and reverse-dependency compatibility, installed original-case behavior, complete native ABI and the strict full-image advisory gate still require separate qualification. No original image finding is cleared by a source build.

The public Debian 5.44.0-2 recipe has 41 patches, five of which touch original test files. It also sets PERL_BUILD_PACKAGING and skips an enc2xs source-hash assertion. Its packaging adaptations are not used here and cannot be presented as unchanged publisher-case proof. No normal configure/build guard is bypassed and no advisory, module, source or scanner finding is excluded.

Sources: [Publisher maintenance releases](https://www.cpan.org/src/), [Debian source recipe](https://deb.debian.org/debian/pool/main/p/perl/perl_5.44.0-2.dsc), [Archive::Tar advisory tracking](https://security-tracker.debian.org/tracker/CVE-2026-9538).
